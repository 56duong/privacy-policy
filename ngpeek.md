# Privacy Policy

**Effective Date:** July 30, 2026

## Overview

NgPeek - Angular DevTools is an unofficial Chrome DevTools extension designed to help developers inspect and debug Angular applications.

## Data Collection

NgPeek does **not** collect, store, transmit, sell, or share any personal information or user data.

When you use the extension, it temporarily reads Angular runtime information from the currently inspected web page using the Chrome DevTools API. This information is processed **locally on your device** and is used solely to provide the extension's debugging and inspection features.

No inspected data is transmitted to external servers.

## Permissions

NgPeek uses the `devtools` permission to integrate with Chrome DevTools and inspect Angular applications opened by the user.

## Data Sharing

NgPeek does not sell, transfer, or disclose user data to any third party.

## Remote Code

NgPeek does not download or execute JavaScript or WebAssembly from external servers. All extension code is packaged with the extension.

## Third-Party Services

NgPeek does not use analytics, advertising, tracking technologies, or cloud storage.

## Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. Any changes will be published on this page.

## Contact

If you have any questions about this Privacy Policy, please contact the developer through the project's GitHub repository or the Chrome Web Store support page.
