Privacy Policy

Effective Date: July 30, 2026

NgPeek - Angular DevTools is an unofficial Chrome DevTools extension that helps developers inspect and debug Angular applications.

Information We Collect

NgPeek does not collect, store, transmit, sell, or share any personal information or user data.

When the extension is used, it temporarily reads Angular runtime information from the currently inspected web page using the Chrome DevTools API. This information is used only to display component details and enable debugging features inside Chrome DevTools.

All processing is performed locally within your browser. No inspected data is transmitted to any external server.

Permissions

NgPeek uses the devtools permission to integrate with Chrome DevTools and inspect Angular applications opened by the user.

Data Sharing

NgPeek does not sell, transfer, or disclose any user data to third parties.

Remote Code

NgPeek does not download or execute JavaScript or WebAssembly from external servers. All extension code is packaged with the extension.

Third-Party Services

NgPeek does not use analytics services, advertising services, tracking technologies, or cloud storage.

Changes to This Policy

This Privacy Policy may be updated to reflect changes to the extension or applicable policies. Updates will be published on this page.

Contact

If you have any questions about this Privacy Policy, please contact the developer through the project's GitHub repository or the Chrome Web Store support page.
